# frontend-course 
A simple HTML webpage created for a Frontend Development Workshop.
The page introduces the workshop and lists the main topics discussed. 

# About the Project
This project is a basics HTML webpage designed to demonstrate fundamental HTML elements such as:
- Headings
- Paragraphs
- Unordered lists
- List items
- Bold text
- HTML document structure

# Topics Discussed
The workshop covers the following 
1- HTML
2- CSS
3- GitHub
4- Dev Tools
